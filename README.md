📝 2. Project Description

The Online Movie Ticket Booking System is a simple Python-based console application designed to provide users with an easy way to view available movies, select a movie, book tickets, and calculate the total ticket price.

This project demonstrates the practical implementation of fundamental Python programming concepts such as:

- 🔢 Variables
- ⚙️ Functions
- 🔄 Loops
- 🔀 Conditional Statements
- 📚 Dictionaries

🎯 3. Objectives

The main objectives of this project are:

- 🎞️ To display a list of available movies.
- 🎫 To allow users to select their preferred movie.
- 🔢 To calculate the total ticket price automatically.
- ✅ To provide booking confirmation options.
- ❌ To allow users to cancel their booking.
- 🐍 To practice fundamental Python programming concepts.

⚙️ 9. Working Process

The program follows a simple and interactive workflow:

When the program starts, users are presented with three options:

1. 👀 View Movies
2. 🎟️ Book Tickets
3. 🚪 Exit

🎫 Ticket Booking
